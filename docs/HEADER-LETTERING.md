# Header lettering: Chinese Rocks — 28 October 2026

The author requested Chinese Rocks-style lettering with both header lines aligned
to the same visible left edge. The supplied Fonts Hut ZIP contains Chinese Rocks
Rg3.002 TTF and no licence document; it is preserved unchanged and not redistributed.

The finished compositions were rendered locally from Chinese Rocks Rg3.104 in the
designer's official free desktop download, accompanied by Desktop EULA v260817.
Designer: Ray Larabie / Typodermic Fonts.
Source: https://typodermicfonts.com/desktop/
Licence guidance: https://typodermicfonts.com/license/
Agreement: https://typodermicfonts.com/assets/documents/Typodermic%20Desktop%20EULA%202026.pdf

The designer permits finished fixed outlined compositions, including complete fixed
graphics inside software. This does not grant working-font embedding, redistribution,
or creation of a reusable glyph library/derivative font. No font ownership or publisher
endorsement is claimed. The lettering is not a new CLEAN font. The stated permitted
finished-artwork use requires no font fee.

Only two complete SVG compositions are distributed:
src/Assets/Lettering/clean-title.svg and clean-subtitle.svg.
The runtime selects/scales these phrases only. No working Chinese Rocks font,
per-character mapping or reusable glyph library is bundled. Source builds need no
installed Chinese Rocks font. The raw official font/agreement remain in ignored scratch/.
